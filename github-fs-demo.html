Setup Instructions

1 Create a GitHub Repository

This will be your agent's persistent file system. Go to GitHub and create a new repository (public or private).

→ Create New GitHub Repository
Recommended: Name it something like agent-workspace or ai-agent-storage
2 Create a Personal Access Token (PAT)

The agent needs a token with repo scope to read/write files.

→ Create GitHub Token (Classic)

Select the repo scope and click "Generate token". Copy the token immediately (you won't see it again).

3 Configure GitHub File System
Usually "main" or "master"
Your GitHub PAT with repo scope
4 Configure Gemini API

The agent uses Google Gemini for intelligence.

→ Get Gemini API Key
